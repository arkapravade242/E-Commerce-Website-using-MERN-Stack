Built an E-Commerce Website using MERN Stack
STEPS TO RUN MY PROJECT:
OPEN VS CODE IN PROJECT FOLLDER DESTINATION
THEN OPEN INTEGRATED TERMINAL FOR BACKEND/FRONTEND AND ADMIN FOLDER SEPARATELY
THEN FIRST OPEN BACKEND INTEGRATED TERMINAL TYPE 'npm run server'
THEN OPEN FRONT END INTEGRATED TERMINAL TYPE 'npm run dev'
AT LAST OPEN ADMIN INTEGRATED TERMINAL TYPE 'npm run dev'
----------->HERE MISSING FILES ARE ADMIN.ENV/FRONTEND.ENV AND BACKEND.ENV BEACUSE SECRET KEY IS STORED IN THESE FILES
